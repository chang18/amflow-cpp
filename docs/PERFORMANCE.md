# Performance

Performance benchmarking is **intentionally deferred** until after the
project has completed broader correctness validation and the
measurements can be run on a dedicated, load-isolated machine.

All previously-reported wallclock numbers (in earlier versions of this
file and in any other doc) were taken on a shared multi-user host with
varying competing load and **should not be relied on**.  They have
been removed.

When a dedicated benchmarking pass is performed, the results will live
back in this file.
